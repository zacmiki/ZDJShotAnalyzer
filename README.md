# ZDJShotAnalyzer
Tool To interpret and Analyze Golf Shots Numbers from ZDJ Simulator

This program started from and idea/request from D.D. who is hosting a SkyTrack/GsPro system and wanted a visual and easy way to present the numbers from the simulator to the users of the indoor facility. 
While tinkering about the possibility many possible ideas and upgrades opened up. 
It is still a very very very preliminary thing And there are many upgrades that are currently being evaluated. 

Possible extra features will include

- Sessions (many shots to detect trends {useful for coaching})
- Efficiency scores for all the various aspects of the shot (teaching/coaching)
- Tendencies (useful for fitting)
- ...
